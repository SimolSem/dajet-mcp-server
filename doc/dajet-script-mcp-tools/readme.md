# Создание MCP-инструментов DaJet Script

Начиная с версии **DaJet MCP Server 1.0.6**, добавлена возможность создавать и подключать произвольные пользовательские MCP-инструменты (tools).

> Ниже следующий пример опирается на использование **CURL**, как это описано в этой [статье](../test-mcp-server-with-curl).

### 1. Настройка и установка MCP-инструмента.

После установки MCP-сервера нужно в каталоге ```scripts``` создать два файла: файл скрипта DaJet Script и его настроек. Каталог ```scripts``` должен находиться в корневом каталоге установки MCP-сервера. Загрузка MCP-инструмента выполняется сервером только при наличии обоих файлов. В случае возникновения ошибки сервер продолжает свою работу без такого инструмента и фиксирует ошибку в логе ```dajet.log```, который автоматически создаётся в корневом каталоге установки MCP-сервера.

**Файл настроек ```test.json```**

Файл настроек необходим для предоставления информации о доступности MCP-инструмента AI-агентам.

```JSON
{
  "name": "test_tool",
  "title": "DaJet Script test tool",
  "description": "DaJet Script test tool demonstrates ability to connect user-defined DaJet Script tools to MCP-server"
}
```

- **name** - уникальное в пределах MCP-сервера имя MCP-инструмента, используемое AI-агентами для его вызова.
- **title** - краткое наименование MCP-инструмента для отображения пользователям.
- **description** - подробное описание функциональности MCP-инструмента для AI-агентов.

**Файл скрипта ```test.djs```**

DaJet MCP Server автоматически выводит JSON-схемы для входных и выходных данных MCP-инструмента. Эту информацию он предоставляет AI-агентам.

Схема входных данных выводится из переменных, объявленных при помощи ключевого слова ```DECLARE```. Переменные, объявленные при помощи ключевого слова ```PRIVATE``` не видны снаружи скрипта. Скрипт может не иметь входных данных, в таком случае все переменные нужно объявлять при помощи ключевого слова ```PRIVATE```.

Схема выходных данных выводится из возвращаемой скриптом переменной, которая указана в команде ```RETURN```. Как правило, схема данных этой переменной определяется соответствующим запросом вида ```SELECT ... INTO @variable```. Тем не менее допускается также возврат скалярных значений простых типов данных DaJet Script.

```SQL
DECLARE @input string -- Входной параметр скрипта
PRIVATE @output array -- Результат выполнения запроса

USE 'MS_TEST'

  SELECT ref  = Ссылка
       , code = Код
       , name = Наименование
    INTO @output
    FROM Справочник.Номенклатура
   WHERE Код = @input

END

RETURN @output
```

### 2. Запуск MCP-сервера и получение списка доступных MCP-инструментов

После создания выше описанных файлов необходимо перезапустить MCP-сервер, чтобы он создал из них новый MCP-инструмент.

> **Важно!** Изменение скрипта DaJet Script или его настроек требует перезапуска MCP-сервера!

Запрос у сервера списка доступных инструментов должен вернуть, наряду со встроенными инструментами, описание нашего нового инструмента.

```JSON
{
  "result": {
    "tools": [
      {
        "name": "test_tool",
        "title": "DaJet Script test tool",
        "description": "DaJet Script test tool demonstrates ability to connect user-defined DaJet Script tools to MCP-server",
        "inputSchema": {
          "type": "object",
          "properties": { "input": { "type": "string" } },
          "required": [ "input" ],
          "additionalProperties": false
        },
        "outputSchema": {
          "type": "object",
          "properties": {
            "ref": {
              "type": "string",
              "pattern": "^{\\d\u002B:[0-9A-Fa-f]{8}-([0-9A-Fa-f]{4}-){3}[0-9A-Fa-f]{12}}$"
            },
            "code": { "type": "string" },
            "name": { "type": "string" }
          },
          "required": [ "ref", "code", "name" ],
          "additionalProperties": false
        }
      }
    ]
  },
  "id": 2,
  "jsonrpc": "2.0"
}
```

### 3. Вызов нового MCP-инструмента AI-агентом

Вызов AI-агентом инструмента возвращает результат выполнения скрипта DaJet Script.

**Запрос AI-агента**

```JSON
{
  "jsonrpc": "2.0", "id": 3, "method": "tools/call",
  "params": {
    "name": "test_tool",
    "arguments": {
      "input": "ФР-00000285"
    }
  }
}
```

**Ответ MCP-инструмента**

```JSON
{
  "result": {
    "content": [],
    "structuredContent": [
      {
        "ref": "{76:6eb028a4-2fbf-22ab-11ec-ec629c3c9156}",
        "code": "ФР-00000285",
        "name": "Авокадо"
      }
    ],
    "isError": false
  },
  "id": 3, "jsonrpc": "2.0"
}
```
